# Welcome to DAIHUM Reslides

To start the slide show:

- `npm install`
- `npm run dev`
- visit <http://localhost:3030>

Open Presenter Mode (with speaker notes, next-slide preview, and timer):

- visit <http://localhost:3030/#/presenter/> (or <http://localhost:3030/presenter/>)

Edit the [slides.md](./slides.md) to see the changes live.
